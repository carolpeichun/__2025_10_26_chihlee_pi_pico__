# 產品需求文檔 (PRD)

## 專案概述

本專案旨在開發一個可在樹莓派（Raspberry Pi）上運行的物聯網監控應用程式，透過 MQTT 協議訂閱並即時顯示智慧家居設備的狀態資訊。

## 技術要求

### 開發框架
- **建議使用 Flask**：由於 Streamlit 可能與樹莓派不相容，建議採用 Flask 作為 Web 應用框架
- **Python 套件檢查**：需檢查目前已安裝的 Python 套件版本，確認是否足夠或適用於本應用程式

## 系統角色

### MQTT 訂閱者
本應用程式作為 MQTT 訂閱者（Subscriber），負責接收並處理來自 MQTT Broker 的訊息。

## 使用者介面需求

### 顯示內容
1. **電燈狀態**：顯示電燈的開關狀態（開/關）
2. **客廳溫度**：即時顯示客廳的溫度數值
3. **客廳溼度**：即時顯示客廳的溼度數值

### 圖表呈現
- **溫溼度圖表**：使用圖表方式呈現溫度和溼度數據
- **時間軸**：圖表的 X 軸代表日期和時間

## 功能規格

### 核心功能
1. **即時監控顯示**：僅提供顯示功能，不包含控制操作
2. **數據儲存**：將訂閱收到的所有資料自動儲存為 Excel 檔案，以便後續分析與記錄
